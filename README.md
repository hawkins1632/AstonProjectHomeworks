## Техническое задание
Реализовать консольное приложение для управления пользователями с использованием Hibernate ORM и СУБД PostgreSQL. 
Код должен быть покрыт Javadoc-комментариями. 
Разработка ведется строго через ветку `develop` и Pull Request'ы с обязательным код-ревью.
